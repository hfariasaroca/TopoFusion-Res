# Reference-result provenance

The files in `reference_results` and `reference_figures` were copied from the author-supplied archive `TopoFusionRes_suplemento_revision.tar.gz`. The archive contains outputs from:

```text
paper_validation_final_seed20260813/
```

Preserved file names and selected subdirectories are recorded in `reference_results/FILE_MANIFEST.csv`. CSV and JSON data are retained unrounded. The public manuscript/supplement may display rounded figures; statistical comparisons must use unrounded values from the original analysis.

- `reference_figures/`: five original supplementary-image files (three PDFs and two PNGs).
- `reference_results/tables/`: selected original evaluation and bootstrap summaries.
- `reference_results/methods/`: selected method/metadata JSON files.

**Provenance limitation:** these are final outputs supplied by the project author, not independently regenerated from original checkpoints in this draft. The source scripts, software environment, raw data and full evaluation command sequence are still to be audited.

**Important:** `Figure05_temporal_evolution.pdf`, `Figure07_lag1_persistence.pdf`, and `Figure08_long_term_trend_signal.pdf` are supplementary inputs; their numeric prefixes come from earlier internal figure numbering. The manuscript's printed figure numbers differ. Their paths in the Overleaf project are not the same as the reference paths in this staging repository.
